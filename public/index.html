Checklist Praktikum AWS EC2 & RDS

1. Security Group EC2

Inbound Rule: Buka port 80/TCP atau 3000/TCP dari 0.0.0.0/0 agar dashboard bisa diakses via browser.

2. Security Group RDS

Inbound Rule: Buka port 3306 (MySQL) atau 5432 (Postgres) dengan Source diarahkan ke Security Group ID milik EC2.

3. Target Group Health Check

Gunakan endpoint /health untuk AWS Application Load Balancer (ALB) health check (mengembalikan status code 200 OK).
